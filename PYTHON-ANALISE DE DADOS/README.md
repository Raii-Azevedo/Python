# 🐍 Python para Análise de Dados – Meu Diário de Aprendizado  

Este repositório reúne meus **pensamentos, aprendizados e experimentos** ao longo da leitura do livro  
**_Python para Análise de Dados – 3ª edição_**, de **Wes McKinney**.  

A ideia é **documentar** o que estou estudando capítulo a capítulo, destacando:  
- 📌 **Conceitos importantes** levantados durante a leitura;  
- ✨ **Novidades** que aprendi (ou pontos que antes não conhecia a fundo);  
- ⚙️ **Aplicações práticas** no meu dia a dia como profissional de dados.  

Cada capítulo terá seu próprio resumo, com **exemplos de código, reflexões e insights**, servindo tanto como registro pessoal quanto como material de consulta para quem também estiver estudando o livro.  

🚀 O objetivo é criar um espaço de aprendizado contínuo, onde teoria e prática caminham juntas.  

---
💡 _Se você também está lendo o livro ou trabalha com Python e análise de dados, fique à vontade para trocar ideias e compartilhar experiências!_
